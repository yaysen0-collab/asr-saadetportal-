ASR-I SAADET PORTALI — ASTRO GECISI

Bu surum mevcut gorunumu ve Firebase tabanli arayuz ozelliklerini korur.
Astro sayfa iskeletini ve makale/SSS sayfalarini tarayiciya hazir HTML olarak
uretir. Sahabe biyografi sayfalari Vercel derlemesinde Firestore verisinden
uretilir.

VERCEL AYARLARI
1. GitHub'a bu proje dosyalarini yukleyin ve Vercel'de once Preview dagitimi
   olusturun. Canli domaine gecmeden once Preview'i kontrol edin.
2. Build Command: npm run build
3. Output Directory: dist
4. Node.js surumu 22.12 veya daha yeni olmali.
5. Sahabe sayfalarinin ve guncel sitemap'in olusmasi icin Firebase ortam
   degiskenlerini Vercel'de koruyun: FIREBASE_SERVICE_ACCOUNT (tercih edilen)
   veya FIREBASE_PROJECT_ID. Gizli anahtarlari GitHub'a koymayin.

ASTRO'YU YERELDE CALISTIRMA
Node.js 22.12+ yuklu bir bilgisayarda proje klasorunde:
  npm install
  npm run dev

Firebase erisimi olan derleme:
  npm run build
  npm run preview

SEO / URL NOTLARI
- Eski /archive.html gibi adresler korunur; Vercel cleanUrls bunlari /archive
  gibi uzantisiz adreslere yonlendirir.
- Makaleler /makaleler/<slug>, sahabe sayfalari /sahabe/<slug> adresindedir.
- sitemap.xml uzantisiz canonical adresleri listeler.
- Giris, hesap, arama ve yonetici sayfalari noindex olarak isaretlenir ve
  sitemap'e eklenmez.
